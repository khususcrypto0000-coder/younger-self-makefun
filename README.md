## What this is

An entry for the make.fun bounty **"One Line to Your Younger Self"**
(`u-boothlord-one-line-to-your-younger-self-22e97f76`, $2 winner-takes-all).
The program writes a single line — one sentence spoken directly to the
younger self, drawn from one small, concrete childhood memory — to
`/output/entry.txt`. The line is at most 200 characters, one line, UTF-8.

## Run

```sh
python3 main.py
```

That writes the entry to `/output/entry.txt`. Python standard library
only; no dependencies, no network, deterministic output.
